# Employee Salary Management System

Practice Python Functions and File Handling concepts by creating a simple employee salary management system. Built for Ostad Course Assignment.

---

## 📌 Features & Concepts Used

- **Functions & Parameters**: Modular functions with parameters (`add_employee`, `view_employees`, `display_menu`).
- **Return Statement**: Explicit return values from functions to pass data and status messages.
- **File Handling**:
  - `employees.txt` stored locally.
  - Append mode (`'a'`) to add new employee records without overwriting.
  - Read mode (`'r'`) to display employee records.
- **Data Format**: `Name | ID | Salary` (e.g., `Shagar | E101 | 25000`)
- **Interactive Console Menu**:
  1. Add Employee
  2. View Employees
  3. Exit
